# BLACKLINE BARBERSHOP — повний шаблон

Це навчальний full-stack проєкт: публічний сайт, онлайн-запис, SQLite-база та панель власника.

## Що потрібно

- Node.js 20 або новіший: https://nodejs.org/
- Visual Studio Code (або інший редактор)
- Підключення до інтернету для завантаження залежностей і зовнішніх фотографій/шрифтів

## Запуск на Windows

1. Розпакуй ZIP у зручну папку.
2. Відкрий папку `blackline-full` у VS Code.
3. Відкрий термінал: **Terminal → New Terminal**.
4. Перевір Node.js:
   ```bash
   node -v
   ```
   Якщо команда не працює, встанови Node.js LTS і перезапусти VS Code.
5. Створи файл `.env` у корені проєкту. Скопіюй у нього вміст `.env.example`.
6. Заміни `ADMIN_PASSWORD` на власний унікальний пароль, а `SESSION_SECRET` — на довгий випадковий рядок (не менше 32 символів).
7. У терміналі виконай:
   ```bash
   npm install
   npm start
   ```
8. Відкрий сайт: http://localhost:3000
9. Панель власника: http://localhost:3000/admin.html

За замовчуванням логін — `owner`. Пароль бери зі свого `.env`, а не з прикладу в документації.

## Як перевірити

1. Відкрий головну сторінку.
2. Обери послугу, майстра й дату.
3. Дочекайся появи вільного часу.
4. Введи тестове ім’я та свій тестовий номер і створи запис.
5. Відкрий `/admin.html`, увійди та перевір, чи з’явилася заявка.
6. Зміни статус на «Підтверджена» і натисни «Зберегти».
7. Спробуй ще раз забронювати той самий час у того самого майстра — система має відхилити повторний запис.

Тестові записи зберігаються в `data/blackline.sqlite`. Щоб повністю очистити тестову базу локально, зупини сервер і видали файл `data/blackline.sqlite`. Це видалить усі записи.

## Як змінити дані під реального клієнта

### Телефон, Instagram, назва та адреса

Відредагуй `.env`:
- `PUBLIC_PHONE=+380...`
- `INSTAGRAM_URL=https://instagram.com/...`

Потім у `server.js` знайди маршрут `/api/config` і заміни:
- `shopName`
- `hours`
- `address`

Назва в логотипі та текстах сторінки зараз прописана в `public/index.html`; заміни `BLACKLINE` на назву клієнта.

### Послуги, ціни, майстри

Перший запуск автоматично додає демонстраційні послуги та двох майстрів. Щоб змінити їх, найпростіше для початку зупинити сервер, видалити `data/blackline.sqlite` і змінити демонстраційні `insert.run(...)` у `server.js`. Після наступного `npm start` база створиться заново з новими даними.

### Фотографії

Заміни посилання на фотографії в `public/index.html` та `public/styles.css`. Використовуй лише фото, які клієнт має право публікувати.

## Важливо перед справжнім запуском

Це робочий локальний MVP, але перед використанням із реальними клієнтами потрібні додаткові налаштування:
- розгорнути Node.js-застосунок на хостингу, який підтримує Node.js і постійне зберігання SQLite-файлу;
- увімкнути HTTPS;
- змінити всі тестові контакти, адресу, ціни, майстрів, години роботи та фотографії;
- встановити сильний унікальний пароль і секрет у `.env`;
- налаштувати резервне копіювання бази;
- перевірити правила приватності й отримання згоди на обробку контактних даних;
- додати повідомлення власнику (email/Telegram) або інтеграцію з календарем, якщо це потрібно бізнесу.

**Не завантажуй `.env`, `data/` або паролі в публічний GitHub-репозиторій.** `.gitignore` уже виключає їх зі звичайного Git-коміту, але все одно перевіряй, що секрети не потрапили в репозиторій.

## Межі поточної версії

- Графік роботи зараз заданий як щодня 10:00–20:00.
- Онлайн-запис зберігається в локальній SQLite-базі сервера.
- Власник бачить записи в панелі та змінює статуси.
- Система не надсилає автоматичні SMS, email чи Telegram-повідомлення.
- Немає окремих вихідних/відпусток майстрів, оплати онлайн, самостійного редагування цін через панель.
- Запис не вважається остаточно підтвердженим, доки власник не зв’яжеться з клієнтом і не підтвердить його.

Не представляй цю версію як повністю готову для виробничого використання, доки не виконані налаштування з розділу вище.
